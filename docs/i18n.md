# I18n — the game's locale dictionary

One dictionary, three consumers. The **JSON files** in
`Brain/lib/born2flap/i18n/locales/*.json` are the single authority for every
user-facing game string. The Ruby Brain reads them directly, the C++ renderer
reads them through a generated header, and the website uses the same key set.

## Locales

| Code | Language | | Code | Language |
|------|----------|-|------|----------|
| `en` | English (canonical) | | `it` | Italian |
| `de` | German | | `pt` | Portuguese |
| `es` | Spanish | | `no` | Norwegian |
| `fr` | French | | `hi` | Hindi |
| `zh` | Chinese (Simplified) | | `ar` | Arabic |
| `ja` | Japanese | | `ru` | Russian |
| `ko` | Korean | | | |

English is canonical; every other language **falls back to English** for
untranslated keys, then to the key itself.

## Keys

Flat, dot-namespaced semantic keys — never styling, never pixels:

```
brand                      hud.altitude            tuning.servo_speed
hud.instruments            hud.climb               tuning.stall_torque
status.core_stopped        wind.calm               hangar.title
desk.title                 dir.n                   bird.ravencrow
```

## Ruby Brain

```ruby
Born2Flap::I18n.t("hud.altitude", lang: "de")   # => "HÖHE"
Born2Flap::I18n.available                       # => ["en", "ar", "de", ...]
```

View controllers resolve `lang` from the render locals (default `en`), and
`.umghaml` templates translate inline via the `t()` helper:

```haml
%Stat{ label: "#{t('hud.altitude')}", value: #{altitude}, unit: " m" }
```

```ruby
Views::FlightHud.render(:cockpit, lang: "ja")
```

## C++ renderer

`Unreal/.../UI/Born2FlapI18n.h` is **generated** from the JSON by
`Brain/bin/gen_i18n_header` (header-only, dependency-free). Do not edit it by
hand — edit the JSON and regenerate.

```cpp
#include "UI/Born2FlapI18n.h"

Born2Flap::I18n::SetLocale(TEXT("de"));
FString Alt = Born2Flap::I18n::T("hud.altitude");   // => "HÖHE"
```

The active locale is set once at startup in `Born2FlapGameMode::InitGame` from
the command line (`-B2FLang=de`) or the URL option (`?Lang=de`). Default is
English.

## Adding a language

1. Copy `Brain/lib/born2flap/i18n/locales/en.json` to `<code>.json` and translate.
2. `ruby Brain/bin/gen_i18n_header` to refresh the C++ header.
3. Rebuild the editor (`arch -arm64 … Build.sh Born2FlapEditor …`).

## Adding a key

1. Add the key to `en.json` (and translate it in every other locale).
2. Regenerate the header.
3. Use `t("new.key")` in Ruby / `Born2Flap::I18n::T("new.key")` in C++.
