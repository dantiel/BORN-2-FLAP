# Interface artwork

The supplied `born2flap-ui-elements.png` and `born2flap-mockups.png` are preserved
in `Art/UI/Reference`. `Art/UI/Elements` contains 43 individually named PNGs and
a manifest of source rectangles and clipping shapes. Buttons, panels and badges
use transparent corners outside their frames. Painted interiors are preserved.
The ornamental brushstroke rings remain in the original reference sheet; they
are not used as rectangular UI controls.

Rebuild the cuts with `Unreal/Born2Flap/Tools/extract_ui_elements.ps1`, then run
`import_ui_elements.py` with Unreal's Python commandlet. Imported assets live
under `/Game/UI/Elements`, use uncompressed UI textures, no mipmaps and no
streaming. These assets are covered by the project's `bCookAll` setting.

The shared UMG renderer uses resolution-independent gold outlines and dark glass
surfaces for panels, buttons and tabs. Panel captions are individually sized
plaques with their own padding, rather than part of a stretched border image.
Location art, slider tracks/thumbs, toggle indicators and weather badges still
use the source sheet. Weather badges use their existing circular frame; the
selected icon stays bright and alternatives are dimmed, with no extra ring.
Main menus have bounded widths, and the one-world-at-a-time browser includes a landscape illustration.
These cards are concept artwork from the sheet, not screenshots of the levels.

Image generation: the built-in imagegen tool was tried with the prompt
"Remove only the blurred backdrop; preserve exact positions, dimensions, colors
and artwork; keep opaque panel/button interiors; make empty areas transparent."
That result retained the backdrop and was rejected. Shipped assets use exact
cuts from the user's original, with geometric clipping, rather than that output.

Native menu pages separate location, weather/time and starting route. Flight
desk tabs separate craft, controls and tuning. The Ruby views also support
page state via telemetry. Controls support a `tooltip` property; explicit help
overrides the default label tooltip. Inter-widget spacing is refreshed after
insertion, so previous children receive the correct trailing gap.

Glass is a UMG background blur behind a procedural UI material,
`/Game/UI/M_HammeredGlass`, generated by `create_glass_ui.py`. The material adds
subtle hammered highlights; this is an optical styling approximation, not
physical diffraction or scene-refraction sampling. Low-quality blur has a
dark fallback brush. All text stays outside the blur layer.

F7 visibility accepts both boolean and numeric wire values. It hides the
cockpit, native instruments, channels and radio, and restores them on the next
press. Modal navigation keeps its own open/close state.

Validation: editor build; Ruby UI tests; weather-menu selection/travel plus
location, weather and route captures; desktop input tests with actual F7 key
events, hidden/restored HUD captures and craft/controls/tuning captures.
