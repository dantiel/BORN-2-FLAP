# Shiomori founder statue

The former hotel fountain contains a 2.8 m bronze founder in a posed, long-haired
adventurer mesh. The figure is **Game ready Pirate Hunter / Viking / Medieval man**
by Chenuka Wijesundara, including **Gambeson** by Leon Steiner, both CC BY 4.0.
Full credits ship in `Unreal/Born2Flap/Content/ThirdParty/Shiomori-assets.txt`.

The original rigged GLB and source metadata are preserved in
`Unreal/Born2Flap/SourceAssets/Founder`. This retains the character's skeleton,
skin weights, coloured textures and material data for later pilot development.
It does not yet implement a selectable pilot, locomotion, controls or animation.

The founder's anatomical right hand holds the kestrel aloft; his left hand
cradles an RC transmitter with two gimbals, sticks, switches, a screen and an
antenna. A flat bronze neck strap passes over both shoulders and converges at
the transmitter clip. `founder_props.py` places these details using the baked
hand/neck sockets in `founder_pose.json`, also regenerated by `bake_founder.py`.

`Tools/bake_founder.py` poses the original skeleton using skinning transforms and
writes a separate static GLB under `Saved/NatureSource/Founder`. It does not modify
the original. The Unreal import retains separate material parts; bronze casting
uses subdued original normal maps and preserves the hair's alpha mask.

The kestrel is a complete static mesh assembled from `Born2FlapRaven::Build`
with Design 2, the same construction used by the flying kestrel. It includes
the correctly oriented fuselage, both shaped wing membranes and the tail fan.
`ABorn2FlapStaticBird` supplies a non-ticking source assembly; `founder_assets.py`
bakes its components and transforms to the reusable mesh
`/Game/Shiomori/Meshes/SM_SM_KestrelStatic`. The merge tool supplies the extra
`SM_` prefix. The source mesh measures 106 cm long and 202 cm across the wings;
the founder's casting uses 0.70 scale. Its refined pose is saved separately as
`/Game/Shiomori/Meshes/SM_KestrelRaised`, with both wings lifted 12 degrees at
their shoulder hinges. The founder's right palm is turned upward underneath it;
the left wrist and controller have been lowered and moved farther to his left.
The shrine's former fuselage-only display
uses this same complete static kestrel at 0.46 scale. Bronze is two-sided so the
thin membranes remain visible from below.

Regeneration: run `python Unreal/Born2Flap/Tools/bake_founder.py`, then the
existing `rebuild_shiomori_campus.py` editor workflow with
`-B2FCampusPlacementOnly`. An existing posed mesh must be reimported after
changing the bake pose; normal campus rebuilds reuse the imported mesh.
Campus verification View 1 is now a close forecourt view of the statue.

Verified 12 October 2026: native editor build succeeded; Python sources compile;
targeted map audit confirms the posed founder and both complete bird displays,
with all 143 volcanic actors preserved. The saved level passed the campus,
weather-experience and audio checks. Final screenshot and log are under
`.setup/founder/founder-final.png` and `.setup/founder/verified-runtime.log`.
One intermediate render encountered the existing intermittent D3D12 startup
GPU page fault; subsequent renders, including the final saved level, passed.

## Missing kestrel diagnosis, 13 October 2026

The failed generation/bake was launched with an unquoted project argument:
`V:/BORN 2 FLAP/Unreal/Born2Flap/Born2Flap.uproject`. PowerShell
`Start-Process -ArgumentList` joins arguments into a command line; an array
entry alone does not preserve quoting. The failed `kestrel-bake.log` records
that unquoted path, the project browser, missing game class, and AppData saves.
The regeneration wrappers then copied incomplete AppData content back over
project content. This removed the bird actors from the actual map.

The PlatformFileJournal warning only disables AssetDiscovery caching because
the NTFS USN journal on V: is inactive. It does not change /Game mounts or
prevent project modules loading. A correctly quoted headless run with
`-nullrhi` restored both kestrels while the same journal warning remained.

Fixed both `.setup/regen-*.ps1` wrappers: quote the project and script paths;
removed the AppData copy-back. `project_guard.py` now checks the actual project
root and game class before generation. A failed kestrel bake raises an error
instead of silently saving a birdless campus. The repair helper also applies
the missing campus XY offset (-12000, 24000) to both bird placements.

Verification: `.setup/founder/repair-missing.log` records the verified project,
the unchanged FileJournal warning, and KESTREL_BAKED_PLACED. The restored map
passed the rendered campus/weather/audio run and the founder bird was visually
confirmed. This was an editor executable in game mode; no new Shipping package
was produced or validated in this repair.
