# Founder source character

`Founder_rigged.glb` is the unmodified licensed source, with skeleton, skin
weights and original materials retained for future pilot work. `source.json`
records its artist, license, public Objaverse mirror URL and SHA-256.

Game ready Pirate Hunter / Viking / Medieval man — Chenuka Wijesundara:
https://sketchfab.com/3d-models/9f51d396733b451bab550b406b067805

Jacket: Gambeson — Leon Steiner:
https://sketchfab.com/3d-models/gambeson-0fc44d2876ed449ca9473e78c83a8d39

Both CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
Obtained through Ai2 Objaverse: https://huggingface.co/datasets/allenai/objaverse

The statue's posed static derivative and bronze materials are generated
separately. See `Tools/bake_founder.py`, `Tools/founder_assets.py` and
`docs/founder-statue.md` at the repository root.
